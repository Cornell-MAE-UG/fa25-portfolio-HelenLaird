For my mechatronics class, our final project was to create a robot for a class-wide competition on the last day of class. The competition required the robot to run autonomously, gathering blocks and sensing color changes on the board while competing against another robot doing the same thing. Working in a group with two other students, we created a robot later named Roberta to gather as many blocks as we could without going off the boards.
